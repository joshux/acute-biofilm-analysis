# acute-biofilm-analysis

Testing Kolpen et al. 2022 (Thorax) — that bacteria in acute lung infection co-express biofilm matrix and fast growth — on public BALF metatranscriptomes (PRJNA1056765, Tang et al. 2025 Sci Data).

Bacterial acute-infection arm only; COVID contrast arm deferred.

- `PLAN.md` — the analysis plan (dataset, panels, pipeline, statistics, guardrails)
- `RESULTS-PILOT.md` — pilot feasibility result (2026-10-09): GO with corrections (panel rebuild, drop NC contrast, contaminant handling)
